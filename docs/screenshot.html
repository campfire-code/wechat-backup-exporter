手机备份聊天导出（本人数据）

把自己 iPhone 备份里的微信聊天记录导出成 HTML / PDF / 文本，在电脑本地保存和查看，全程在本机处理。

怎么用

  1. 用 iTunes（Mac 用访达）把 iPhone 备份到电脑，备份时不要设置加密口令
  2. 解压下载的压缩包，运行 WechatExport.exe（Windows）或 WechatExporter（Mac）
  3. 按界面提示选择备份和导出目录，以及要导出的聊天和格式
  4. 菜单「选项」里可设置页面加载方式、过滤功能和增量导出（只导出上次之后的新消息）
交付形式　桌面软件压缩包（Windows 64 位 / Mac x64），解压即用；导出 PDF 需要 Chrome 或 Edge
